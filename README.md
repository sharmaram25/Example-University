# 🎓 Example University

## 🌐 Live Demo

**[Visit Example University Website](https://exampleuni.netlify.app/)**


## 📝 Description

Example University is a modern, responsive university website built with React, TypeScript, and Tailwind CSS. This project demonstrates a comprehensive university web presence with pages for academics, admissions, campus life, and more.

## ✨ Features

- 📱 Fully responsive design that works on all devices
- 🎨 Modern UI/UX built with Tailwind CSS
- 🔄 Component-based architecture using React
- 📄 Multiple page sections including:
  - Home page with highlights and news
  - Academic programs and courses
  - Admissions information
  - Campus life and student resources
  - Research initiatives
  - Alumni network
  - Library resources
  - Career services
  - Contact information

## 🛠️ Technologies Used

- **Frontend Framework**: React with TypeScript
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **Deployment**: Netlify

## 🚀 Getting Started

### Prerequisites

- Node.js (v16+)
- npm or yarn

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/sharmaram25/Example-University.git
   cd Example-University
   ```

2. Install dependencies
   ```bash
   npm install
   # or
   yarn
   ```

3. Start the development server
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open your browser and visit `http://localhost:5173`

## 📦 Build for Production

```bash
npm run build
# or
yarn build
```
